# Data center interativo three.js

Mundo 3D interativo ambientado em um **data center futurista**, desenvolvido
em Three.js.

O usuário explora o ambiente em primeira/terceira pessoa, percorrendo
corredores de racks, robôs e uma IA, sob uma iluminação pensada
para criar a atmosfera futurista do lugar.

## Destaques

- Navegação com movimento independente de frame rate
- Iluminação com leds e sombras configuradas
- Materiais com texturas, mapeamento UV, normal/bump map e rugosidade
- Modelos 3D externos em OBJ e glTF/GLB
- Modo diagnóstico: wireframe, profundidade, back-face culling,
  frustum de uma segunda câmera e contadores do `renderer.info`

## Como executar

    npm install
    npm run dev
